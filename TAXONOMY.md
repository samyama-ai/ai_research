# Taxonomy — AI Research topics

The topic map. Seeded from ERA V5; grows as problems are added. Each topic is `topics/NN-topic-slug/`.

| # | Topic | Scope |
|---|---|---|
| 01 | **tokenization** | BPE/unigram/byte vocabularies, fertility, multilingual fairness, compression |
| 02 | *attention* | (reserved) attention mechanisms, KV-cache, long-context |
| 03 | *training* | (reserved) optimization, schedules, scaling, data curricula |
| 04 | *alignment* | (reserved) RLHF/DPO, evaluation, safety |
| 05 | *retrieval-and-agents* | (reserved) RAG, tool use, agentic systems |

> Reserved topics are placeholders — add the folder when the first problem lands there.
